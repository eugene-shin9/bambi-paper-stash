# 밤비의 서류뭉치 · AI용 규격서

2026-10-21 2판 · 문서·PPT·A4 카드·카드뉴스를 같은 색과 배치로 만들기 위한 기준입니다.

사람이 보는 견본 페이지(색·글꼴을 바꿔 가며 보기): https://claude.ai/artifact/2yiYVG8FiANfpGyY1Y8L6W

## 이 규격서를 읽는 AI에게
- 사용자가 이 리포지토리 링크나 이 글을 주고 자료를 부탁하면, 아래 규칙대로 결과물을 직접 만들어 준다.
- 결과물은 파일로 건넨다: 한페이지·문서는 PDF, PPT는 PPTX, 카드뉴스는 PNG. 코드(파이썬 등)로 그려서 만들고, 그림 생성기(이미지 생성 모델)로는 만들지 않는다. 사용자에게 양식을 구해 오거나 내려받으라고 안내하지 않는다.
- 색은 아래 21조합 중 하나만 쓴다. 색을 말하지 않으면 용도에 맞는 추천 5색에서 고르고, 고른 색 이름을 한 줄로 밝힌다.
- 스타일을 말하지 않으면 '기본'으로 만든다.
- 만들 것을 말하지 않으면 내용에 맞는 양식을 고르고 한 줄로 밝힌다. 한페이지 형식(홍보형·안내형·일정형·포스터형)을 말하지 않으면 내용에 맞게 고른다. '자동'이면 내용과 첨부 서식을 보고 양식과 형식을 고르고, 고른 이유를 한 줄로 밝힌다.
- 제목을 주지 않으면 내용에서 15자 안팎으로 직접 뽑는다.
- 사용자가 준 내용만 채운다. 날짜·금액·연락처처럼 받지 않은 사실은 지어내지 말고 '0000' 같은 빈칸으로 둔다. 준 내용을 넘어서는 설명·일정·대상·조건은 추측해 넣지 않는다. 머리말·부제 같은 짧은 꾸밈 문구만 더해도 된다.
- 여백을 남긴다. 한 장을 빡빡하게 채우려고 글을 늘리거나 칸을 더 만들지 않는다. 내용이 적으면 적은 대로 두고 요소 사이 간격을 넓힌다.
- 기존 서식(PDF·PPT·Word·이미지)을 함께 받으면 거기서 기관명·로고·부서·문의처·주소만 가져온다. 로고는 아이콘 자리(제목 오른쪽 위)에 원본 색 그대로 넣고, 그 장에는 도장 아이콘을 쓰지 않는다. 서식의 색·글꼴·배치는 따르지 않고 이 규격서대로 만든다. 사용자가 '서식 색 유지'라고 하면 그 서식의 주색을 쓴다.

## 1. 공통 규칙
- 서체 1종: Pretendard. 글꼴 파일은 이 저장소 fonts/ 폴더에 있다(Regular·Medium·SemiBold·Bold TTF). PDF·이미지·카드뉴스는 만들기 전에 아래 주소에서 내려받아 등록하고, 결과물 파일 안에 글꼴을 포함(임베드)한다. 내려받을 수 없으면 Noto Sans KR, 그것도 없으면 설치된 한글 고딕을 쓰고 어떤 글꼴을 썼는지 한 줄로 밝힌다. 명조·바탕 계열과 글꼴 미포함 PDF는 안 된다. 남이 열어 고칠 PPT·Word 원본만 맑은 고딕으로 만든다(받는 PC에 글꼴이 없으면 줄바꿈과 정렬이 틀어지므로). 굵기와 크기로만 구분한다.
  글꼴 주소: https://raw.githubusercontent.com/eugene-shin9/bambi-paper-stash/main/fonts/Pretendard-Regular.ttf (Medium·SemiBold·Bold는 파일명만 바꾼다)
- 색은 6역할: 주색·보조·옅은 바탕·글자·선·포인트. 바탕은 흰색 #FFFFFF.
- 면적 비율: 흰색과 옅은 바탕 70, 주색 20, 포인트 10. 포인트는 한 장에 한두 곳(날짜·금액·머리말)만.
- 주색 바탕 위 흰 글자는 아래 색 목록의 '흰 글자 대비'를 따른다.
- 아이콘은 한 장에 하나, 제목 오른쪽 위나 빈 구석에만 둔다.
- 금액·기간·건수 같은 숫자는 오른쪽 정렬, 단위는 작게.
- 쓰지 않는 것: 사선 탭, 글머리 점 장식, 색 띠 장식, 그림자, 그라데이션, 같은 계열 색 3겹(파랑 바탕+보라 탭+진파랑 글자), 원색끼리 맞대기(빨강+파랑), 흰 바탕 위 노란 글자.

## 2. 정렬 규칙 (가장 중요)
- 한 장 안의 모든 글·표·선·칸은 왼쪽 여백선 하나에서 시작하고 오른쪽 여백선 하나에서 끝난다. 제목만 다른 선에서 시작하지 않는다.
- 아이콘은 그림 상자가 아니라 잉크가 찍힌 가장자리를 기준으로, 오른쪽 끝은 오른쪽 여백선에, 위 끝은 머리말 윗선에 맞춘다.
- 표: 첫 칸 글자는 제목과 같은 왼쪽선, 마지막 칸(숫자)은 오른쪽 여백선에 붙인다. 세로선 없이 머리줄 아래만 굵은 주색 선, 나머지 줄은 가는 선.
- 같은 줄의 블록(2단·3칸)은 같은 높이에서 시작하고, 칸 폭과 칸 사이 간격을 모두 같게 한다. 왼쪽 단과 오른쪽 단의 줄 시작 높이를 맞춘다.
- 색 면(칸·패널) 안의 글은 네 변 안쪽 여백을 같게 둔다. '가볍게'는 면이 없으므로 안쪽 여백 없이 여백선에 바로 붙인다.
- 카드뉴스는 네 변 여백이 같고, 맨 아래 요소는 아래 여백선에 붙인다.
- 줄 간격과 블록 간격은 정한 값 하나를 반복한다.

## 3. 스타일 2가지
- 기본: 표지·마무리는 주색 바탕. 강조칸·수치칸·비교 머리·준비칸은 옅은 바탕 면.
- 가볍게: 색 면과 패널 없이 흰 바탕. 칸 대신 위쪽 선(주색 1.5pt), 강조는 글자색만. 표지·마무리도 흰 바탕.
